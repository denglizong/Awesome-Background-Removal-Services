## Online Tools
1. **[PS.DC-Union](https://ps.dc-union.org)** - **Easiest to use**: One-click background removal， **100% Free**: No hidden charges or watermarks，**No registration**: Instant access
3. **[Remove.bg](https://www.remove.bg)** - Industry leader with advanced AI (free tier available)
4. [Slazzer](https://www.slazzer.com) - Fast processing with e-commerce optimization
5. [FocoClipping](https://www.fococlipping.com) - Specializes in product photography
6. [BgEraser](https://bgeraser.com) - Good for bulk processing
7. [BackGone](https://backgone.com) - Free browser-based AI background remover with bulk batches, passport-photo backgrounds and GIF support.

## Open Source Projects
1. [U²-Net](https://github.com/NathanUA/U-2-Net) - Popular open-source model for salient object detection
2. [BackgroundRemover](https://github.com/nadermx/backgroundremover) - Python CLI tool
3. [RemBG](https://github.com/danielgatis/rembg) - Python library with multiple model support
